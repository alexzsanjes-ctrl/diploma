# Процедура запуска автотестов
Для запуска автотестов на компьютере должен быть установлен _Docker Desktop_ и _IntelliJ IDEA_, а также включена виртуализация
- Запустить _Docker Desktop_
- Открыть проект в _IntelliJ IDEA_
- Скачать образы, выполнив по очереди команды в терминале:
  - _docker pull mysql:8_
  - _docker pull dhi.io/postgres:18-alpine3.22-dev_
- Создать образ на основе симулятора 
  - Выполнив переход в gate-simulator 
    - _cd gate-simulator_ 
  - И создать образ 
    - _docker image build -t gate-node-image:1.0 ._
- Когда все образы будут сформированы, выполнить команду _docker-compose up_
  - Дождаться завершения запуска всех контейнеров
  - Открыть новый терминал (2) и выполнить команду docker container ls, чтобы убедиться, что все контейнеры запущены.
- Выполнить переход в artifacts
  - _cd artifacts_
- Запустить aqa-shop.jar
  - _java -jar aqa-shop.jar --spring.profiles.active=mysql_
- После успешного запуска файла jar, убедиться что страница http://localhost:8080/ доступна
- Открыть новый терминал (3) и выполнить запуск автотестов
  - _./gradlew clean test_
- После успешного выполнения автотестов сформировать отчет и открыть для просмотра в браузере 
  - _./gradlew allureServe_

<details>
  <summary>Установка Docker Desktop</summary>
Шаг 1: Подготовка
Убедитесь, что у вас включена функция WSL 2.
Откройте PowerShell от имени Администратора и выполните команду:
wsl --install
Важно: После выполнения команды обязательно перезагрузите компьютер. 

Шаг 2: Скачивание и установка
Перейдите на страницу загрузки Установите Docker Desktop на Windows. с официального сайта и скачайте Docker Desktop Installer.exe.
Запустите скачанный файл.
В процессе установки убедитесь, что отмечена галочка «Use WSL 2 instead of Hyper-V» (Рекомендуется).
Дождитесь завершения процесса и нажмите Close and restart (Закрыть и перезагрузить) для применения всех системных изменений.

Шаг 3: Первый запуск
Запустите Docker Desktop через меню Пуск.
При первом открытии появится окно с лицензионным соглашением. Примите его, нажав Accept.
Дождитесь, пока иконка в левом нижнем углу приложения станет зеленой (статус: Docker Desktop is running).
</details>
