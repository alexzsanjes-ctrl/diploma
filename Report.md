# Отчет по итогам тестирования
Отчет по результатам тестирования веб-сервиса, который предлагает купить тур по определенной цене, а таже взаимодействующих с ним 2-х сервисов для обработки платежей: платежному и крединтому.
- Реализовано 48 тест-кейсов, из них:
    - 24 для плтежного серсвиса
    - 24 для кредитного сервиса
- Общий процент успешных тест-кейсов 72.91%, не успешных 27.09%
