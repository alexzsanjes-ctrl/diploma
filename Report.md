# Отчет по итогам тестирования
Отчет по результатам тестирования веб-сервиса, который предлагает купить тур по определенной цене, а также взаимодействующих с ним 2-х сервисов для обработки платежей: платежному и кредитному.
- Реализовано 48 тест-кейсов, из них:
    - 24 для плтежного серсвиса
    - 24 для кредитного сервиса
- Общий процент успешных тест-кейсов 72.91%, не успешных 27.09%

Тесты преимущественно затрагивают работу веб-сервиса и реализуют проверку реагирования формы при заполнения полей различными данными, а также ответ приложения в случае успешной отправки формы. Отдельные тесты также выполняют необходимые запросы в БД для подтверждения выполнения операции, связанных со статусом операции, либо суммой покупки. Нужно отметить, что выполнение тестовых сценариев, связанных с успешной отправкой формы занимает более длительное время, т.к. происходит обработка платежа. Нужно учитывать это время при автоматизации тестовых сценариев.
